What this teaches

The client no longer chooses a server.

Nginx is acting as both a reverse proxy and a Layer 7 load balancer. It receives an HTTP request, selects the next healthy upstream in round-robin order, and returns that server's response through one stable client-facing address.

  • Horizontal scalingMore replicas can share the same workload.
  • One client addressReplica addresses stay behind the load balancer.
  • Failure isolationIf one replica disappears, requests can continue through the others.
