What changed

The path now chooses the service.

A load balancer chooses among replicas of the same service. An API Gateway first chooses which service owns the request. These responsibilities can later be combined: the gateway chooses Catalog, then a Catalog load balancer chooses a replica.

  • One public APIClients no longer track six service addresses.
  • Path-based routingEach resource prefix maps to its owning service.
  • Central entry pointCross-cutting policies can be added before requests reach services.
