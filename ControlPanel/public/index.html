The request journey

Build the path. Then scale it.

Each lesson keeps what you learned and introduces one new infrastructure decision.

  1. 01 Foundation Hitting the service directly Understand the simplest possible request path and its limitations. Client → Catalog Service Direct requestSingle server Explore lesson →
  2. 02 Traffic control Reverse Proxy and response caching Hide the origin, move connection work, and serve repeated responses faster. Client → Nginx cache → Catalog Service Reverse proxyCaching Explore lesson →
  3. 03 Horizontal scaling L7 Load Balancer Distribute HTTP requests across multiple instances of the same service. Client → L7 Load Balancer → 3 Catalog replicas Round robinReplicasL7 Explore lesson →
  4. 04 Service routing API Gateway Give clients one entry point and route each API to its owning service. Client → API Gateway → User / Catalog / Order Path routingSingle entry point Explore lesson →
  5. 05 Hybrid architecture Gateway + Load Balancer Scale only the busy service while routing quieter services directly. Gateway → L7 Load Balancer → Catalog replicas Selective scalingL7 Explore lesson →
  6. 06 High availability Load-balanced API Gateways Remove the gateway SPOF by distributing connections across gateway replicas. Edge L4 LB → 2 API Gateways → Services L4Gateway replicasFailover Explore lesson →
  7. 07 Content delivery Local CDN Serve cacheable product responses before traffic reaches the origin. Client → CDN → Edge → Gateway → Services Edge cacheLower latency Explore lesson →
